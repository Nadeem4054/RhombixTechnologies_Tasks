## 📚 Commands Covered

### 1. **File Operations** (10 Commands)
- Navigation: `pwd`, `ls`, `cd`, `mkdir`
- File Management: `touch`, `cp`, `mv`, `rm`, `cat`
- File Editing: `nano`, `vim`

### 2. **File Permissions & Ownership** (3 Commands)
- `chmod` - Change file permissions
- `chown` - Change file owner and group
- `ls -l` - View permissions in detail

### 3. **System Information** (8 Commands)
- `uname -a` - System information
- `df -h` - Disk space usage
- `du -sh` - Folder size
- `free -h` - Memory usage
- `top` - Running processes
- `ps aux` - Process list
- `whoami` - Current user
- `id` - User ID and groups

### 4. **User & Group Management** (4 Commands)
- `sudo` - Administrator privileges
- `useradd` - Create users
- `userdel` - Delete users
- `passwd` - Change passwords

### 5. **Package Management** (5 Commands)
- `apt update` - Update packages
- `apt upgrade` - Upgrade packages
- `apt install` - Install software
- `apt remove` - Remove software
- `apt search` - Search packages

### 6. **Text Processing & Searching** (4 Commands)
- `grep` - Search text patterns
- `find` - Find files
- `wc` - Count lines
- `sort` - Sort content

### 7. **Archive & Compression** (4 Commands)
- `tar` - Create/extract archives
- `gzip` - Compress files
- `gunzip` - Decompress files

### 8. **Network & Connectivity** (5 Commands)
- `ping` - Test connectivity
- `ifconfig` - Network configuration
- `netstat` - Port connections
- `curl` - Fetch URLs
- `wget` - Download files

### 9. **System Monitoring & Logs** (3 Commands)
- `htop` - Process monitoring
- `journalctl` - System logs
- `dmesg` - Kernel messages
